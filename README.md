# AIエージェント設定 (`.agents`)

> [!NOTE]
> このディレクトリには、このワークスペース内で動作するAIエージェント向けの設定ファイル、動作ルール、およびカスタムスキルが含まれています。

このディレクトリは、AIエージェントの動作、ルール、ワークフローを標準化し、様々なAIツール間で一貫した最適な開発体験を保証します。

## ディレクトリ構造

- **[`AGENTS.md`](./AGENTS.md)**: 全てのAIエージェントが実行時に従うべき中核となるルール、動作原則、ワークフローを定義します。
- **[`skills/`](./skills/)**: 特定のタスクに対してエージェントの機能を拡張するカスタムスキルが含まれています。
- **[`memo.md`](./memo.md)**: クロスプラットフォームのAIエージェントの仕様、互換性、標準規格に関するドキュメントとメモです。

## 利用可能なスキル

`skills` ディレクトリには、エージェントが動的に読み込める以下の専用ツールが含まれています：

- `concise-grounded-replies`: 簡潔で定型文を使用しない、根拠に基づいた回答を強制します。
- `create-architecture-spec`: Mermaid図を用いた高品質なアーキテクチャ仕様書を生成します。
- `create-readme`: 構造化された魅力的なREADMEファイルを自動生成します。
- `drawio`: 図、フローチャート、アーキテクチャモデルの作成や処理のリクエストに対応します。
- `grilling`: 厳密な質問と批判的分析により、アイデアや計画のストレステストを行います。
- `pdf`: PDFドキュメントの処理、読み取り、操作を行います。
- `ponytail`: 最もシンプルで、怠惰で、最小限のコードソリューション（YAGNI）を強制します。
- `skill-creator`: カスタムスキルの作成、編集、テスト、最適化を行うツールです。
- `test-driven-development`: 厳密なTDD（テスト駆動開発）の実践を通じて、機能実装とバグ修正を導きます。
- `ui-ux-pro-max`: 高度なUI/UXデザインインテリジェンス、スタイル、カラーパレットを提供します。
- `unreal-engine`: Unreal Engine 5のビルド、テスト、パッケージング、コードフォーマットタスクを自動化します。
- `verification-before-completion`: 作業を完了とする前に、すべての作業が具体的な証拠をもって検証されていることを確認します。

## 使用方法

これらの設定は、互換性のあるAIエージェント（Google Antigravityなど）によって自動的に検出されます。エージェントは `AGENTS.md` に指定された基本指示に従い、ユーザーのプロンプトやタスクの要件に基づいて特定のスキルをオンデマンドで有効にします。
