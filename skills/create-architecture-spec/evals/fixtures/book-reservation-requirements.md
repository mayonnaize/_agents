# 書籍予約API 要件

- 認証済み利用者は、在庫が貸出中の書籍を1冊ずつ予約できる。
- 同じ利用者が同じ書籍へ複数の有効な予約を作ることは禁止する。
- 予約作成は `POST /v1/books/{bookId}/reservations` で受け付ける。
- リクエストには `Idempotency-Key` ヘッダーを必須とする。
- 正常時は `201` と `reservationId`、`bookId`、`userId`、`status`、`expiresAt` を返す。
- 書籍が予約対象外なら `409`、未認証なら `401`、他人の予約を読む操作は `403` とする。
- 予約の有効期限は作成から24時間とし、期限切れ後は次の利用者へ権利を移す。
- 同一書籍への同時予約では、受付順が早い利用者だけを有効にする。
- 予約作成から応答までの95パーセンタイルを300ミリ秒以下とする。
- 監査のため、作成、期限切れ、取消しを90日間記録する。
- データベース製品、クラウド、担当チームは未決定である。
