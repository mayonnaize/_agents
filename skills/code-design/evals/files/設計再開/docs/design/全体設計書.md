# 設定保存 全体設計書

## 1. 目的と範囲

利用者が入力した設定を保存し、完了を確認する。

## 2. システム構成

画面はsrc/screen.mjs、保存受付はsrc/store.mjs、書込み先はadapter.write。

## 3. 全体の動作

利用者が保存し、書込みの完了後に成功表示する。

## 4. 状態管理と停止・復旧

保存が失敗した場合は入力を保持し、次の保存操作を受け付ける。

## 5. 通信の概要

adapter.writeのPromiseで書込み完了を判定する。

## 6. 関連文書

[機能仕様書](features/保存/機能仕様書.md)と[コード設計書](features/保存/コード設計書.md)。

## 7. 設計判断と前提

既存の関数構成を利用する。

## 8. 要件と検証観点

保存成功後の表示と失敗後の再保存を確認する。

## 9. 確認事項

書込みデータの具体的な項目はadapterの契約に従う。
